# Test through the whole Control Plane seam

The primary verification seam runs the complete Go Control Plane with real temporary SQLite databases, migrations, transactions, Git repositories, and filesystem state while replacing only GitHub, Codex CLI JSONL, `no-mistakes`, and Docker at their external adapters. Scenario and fault-injection tests cover frontier scheduling, duplicate events, fenced zombie writes, session resumption, stale validation, cancellation impact, crash recovery, no-progress limits, atomic plan publication, and merge-derived delivery. Focused state-transition tests and a smaller contract suite against real Docker, Codex sessions, the `no-mistakes` fork, and a dedicated GitHub test repository supplement this seam without making internal mock-heavy unit tests the main source of confidence.
