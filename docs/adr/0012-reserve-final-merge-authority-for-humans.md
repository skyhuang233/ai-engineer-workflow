# Reserve final merge authority for humans

The Delivery Controller may validate, publish, update, and monitor a pull request but cannot decide or execute its final merge. Only an authorized human reviewer may merge or enqueue a Merge-Ready revision; a new head, relevant base-branch change, or new Review Feedback invalidates that state and requires renewed validation. GitHub Merge Queue and branch protection are optional server-enforced strengthening where the repository plan supports them, while Gateway fencing, current-head checks, and sole human merge authority remain the portable baseline.
