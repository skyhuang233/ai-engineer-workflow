# Bind one durable agent session to each Executable Ticket

Each Executable Ticket has exactly one currently accountable Ticket Agent backed by a resumable Ticket Session, and all review feedback is routed directly back to that same session until the ticket is Delivered or Cancelled. The Control Plane stores only the runtime's stable session handle instead of rebuilding or injecting a separately managed conversation summary; context retention and compaction are delegated to the agent runtime. Worker Runs remain bounded execution episodes and containers remain replaceable, so durable responsibility does not require durable compute. Responsibility may transfer to a replacement agent only after the original session is confirmed permanently unrecoverable, and that exceptional transfer must be explicit and auditable.
