Generation-based Windows Bundles begin at `platform-v0.0.1`. Fresh and explicit
upgrade select only latest eligible stable; repair and unfinished attempts stay
exact-target-pinned. The product has no 0.1.x detector, adopter, migration, or
compatibility branch and refuses unknown nonempty Workflow Homes.
